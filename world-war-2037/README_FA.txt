# NEX ARENA — Mobile FPS prototype

این نسخه یک نمونه اولیه سه‌بعدی تحت وب است:
- دید اول‌شخص (FPS)
- تیم قرمزِ رباتی در برابر بازیکن
- کنترل لمسی: جوی‌استیک سمت چپ، کشیدن انگشت در سمت راست برای چرخش دوربین، دکمه TAG
- کنترل رایانه: WASD یا کلیدهای جهت‌نما، حرکت ماوس برای نگاه، Space برای TAG
- مسابقه دو دقیقه‌ای

## اجرا در Android با Pydroid 3
1. پوشه ZIP را استخراج کن.
2. در Pydroid 3 فایل `app.py` را باز کن.
3. دکمه Run را بزن.
4. مرورگر گوشی را باز کن و برو به `http://127.0.0.1:8000`

نیازی به نصب pygame یا Flask نیست؛ سرور از کتابخانه استاندارد Python استفاده می‌کند.

## نکته
برای بارگذاری موتور Three.js، مرورگر هنگام اجرای بازی به اینترنت نیاز دارد. این نسخه یک نمونه اولیه قابل‌بازی است، نه بازی آنلاین چندنفره یا محصول نهایی. گیم‌پلی آن علمی‌تخیلی و غیرواقع‌گراست و مکانیک TAG انرژی دارد.
